# api/ 与 celery-worker/ 之间必须逐字节一致的文件。
#
# 两个服务共享大量代码，各存一份。这份清单是**当时的事实快照**：生成时这些
# 文件在两侧完全相同，因此把它们钉住，让「只改了一侧」变成 CI 上的红灯 ——
# 此前只有约定，没有任何东西会在漏改时失败。
#
# 用法：
#   - 新增共享文件时，把路径加到这里（或在文件里写 MIRRORED-FILE 标记，两种都认）。
#   - 某个文件**确实**要在两侧分化时，从这里删掉并在提交信息里说明为什么 ——
#     删除是一个需要解释的动作，而不是随手让它漂走。
#
# 路径相对各自的服务根目录。空行与 # 开头的行会被忽略。
