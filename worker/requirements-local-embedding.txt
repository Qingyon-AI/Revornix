# 默认配置走云端（ALI_DASHSCOPE_EMBEDDING_ON=True），那种部署一次都不会加载
# 本地引擎 —— 而 torch 的 wheel 是 527 MB、装完约 1.3 GB。此前它在
# requirements.txt 里、且被 engine/__init__.py 在顶层 import，于是每台机器、
# 每个镜像、每次构建都在为一个永不执行的分支付钱。
#
# 要用本地推理就：pip install -r requirements-local-embedding.txt
# 不装而又把 ALI_DASHSCOPE_EMBEDDING_ON 关掉的话，get_embedding_engine() 会
# 抛 ImportError —— 那是有意的，比静默多背 1.3 GB 好。
